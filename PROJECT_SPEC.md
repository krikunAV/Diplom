# PROJECT SPEC: Система автоматизации расчётов ПБ ТЭК

## 1. Описание проекта

Название:
Разработка программного комплекса для автоматизации расчётов при составлении паспорта безопасности объекта газовая котельная.

Назначение:
Система предназначена для автоматизации инженерных расчётов последствий аварий на объектах ТЭК (в первую очередь — газовые котельные) и формирования отчётной документации.

Пользователь:
- инженер-проектировщик  
- специалист по промышленной безопасности  
- организации ТЭК  

Основной принцип:
Пользователь вводит исходные данные → система автоматически выполняет расчёты → формирует отчёт.

## 4. Основная логика системы

Система построена по принципу:

👉 МОДУЛЬНОЙ ЦЕПОЧКИ РАСЧЁТОВ (pipeline)

### Pipeline ТВС:

1. Расчёт массы выброса  
2. Расчёт энергозапаса  
3. Расчёт параметров ударной волны (ΔP)  
4. Расчёт импульса  
5. Расчёт probit-функций и зон поражения  

Каждый шаг:
- реализован отдельным модулем  
- передаёт результат следующему  

👉 Pipeline линейный, но может изменяться в зависимости от сценария

---

## 5. Сценарии (ПОУО)

Реализовано:
- трубопровод природного газа высокого давления (наружный)

Планируется:
- резервуарный парк  
- трубопровод среднего давления  
- СУГ  
- котельные  
- испарительные установки  

Важно:
Каждый сценарий должен формироваться из набора расчётных модулей.

---

## 6. Расчётная модель

Рассчитываются:

- масса выброса  
- энергозапас  
- избыточное давление (ΔP)  
- импульс положительной фазы  
- probit-функции  
- зоны поражения  

Особенности:
- формулы заданы жёстко (соответствие нормативам)  
- расчёты выполняются мгновенно  
- используются смешанные единицы измерения  

---

## 7. Нормативная база

Основной документ:
- Приказ Ростехнадзора №412 (2022)

Также используются:
- методики МЧС  
- ГОСТ  
- Минэнерго  

Важно:
Все расчёты должны соответствовать нормативным документам.

✔ понимать архитектуру проекта  
✔ сохранять pipeline
