<a name="scenario"></a>
## Описание сценария

**Код сценария:** POUO1  
**Наименование:** Резервуарный парк (тип топлива, количество и объём каждой ёмкости)  
**Топливо:** Дизельное топливо (`diesel`) или СУГ пропан-бутан (`lpg`)  
**Пространство:** Наружная установка (outdoor)  
**Параметры ввода:** объём резервуара `tank.volume_m3`, количество резервуаров `tank.count`, площадь пролива `spill.area_m2`, продолжительность `spill.duration_s`

### Физическая картина

**Дизельное топливо** хранится при атмосферном давлении в надземных или подземных резервуарах. При разгерметизации образуется **пролив** жидкости. Пары дизеля медленно испаряются с поверхности пролива — возможно воспламенение с образованием **пожара пролива** или, при накоплении достаточной концентрации паров, **взрыва паровоздушной смеси (ТВС)**.

**СУГ (сжиженный газ — пропан-бутан)** хранится под давлением в жидком состоянии. При разгерметизации резервуара избыточное давление мгновенно сбрасывается — жидкость **вскипает** (flash evaporation). Пар образует облако, которое при воспламенении даёт **струйный факел (Jet Fire)** или **огненный шар BLEVE** (при мгновенном разрушении всего резервуара).

### Рассматриваемые сценарии последствий

| Топливо | Сценарий | Описание |
|---|---|---|
| `diesel` | **Пожар пролива (Pool Fire)** | Горение жидкости на земле |
| `diesel` | **Взрыв ТВС** | Взрыв накопившихся паров дизеля |
| `diesel` | **Огненный шар** | Воспламенение паровоздушного облака |
| `lpg` | **Факельное горение (Jet Fire)** | Горение струи вскипевшего СУГ |
| `lpg` | **Огненный шар BLEVE** | Взрывное вскипание всего резервуара |

<a name="flowchart"></a>
## Схемы расчёта

### Ветка diesel

```
Входные данные
  ├─ tank.volume_m3, tank.count
  ├─ spill.area_m2, spill.duration_s
  └─ fuel: Pnas_pa, M_g_mol, Eud0, Ef_pool, burn_rate
        │
        ▼
 [Р.1] Масса в резервуарном парке
  └─ m_total = V × N × ρ_liq
        │
        ▼
 [Р.2а] Испарение из пролива
  ├─ W = 10⁻⁶ · η · Pнас · √M     (ГОСТ К.1)
  ├─ m_evap = W · F_пр · τ ≤ m_total
  ├─ m_cloud = m_evap · Z
  └─ E = m_cloud · Eud
        │
   ┌────┴────────────────┐
   ▼                     ▼
[Р.6] ТВС взрыв     [Р.4а] Огненный шар
 ΔP(r), I+(r)        (m = m_evap)
 зоны стекло/здания/люди
        │
        ▼
 [Р.5] Пожар пролива
  D_pool, L_F (Томас), q(r), зоны
        │
        ▼
 [Р.7] Число людей в зонах поражения
```

### Ветка lpg

```
Входные данные
  ├─ tank.volume_m3, tank.count
  ├─ spill.flash_fraction, spill.pool_evap_fraction, spill.duration_s
  └─ fuel: Ef_jet_kw_m2
        │
        ▼
 [Р.1] Масса в резервуарном парке
  └─ m_total = V × N × ρ_liq
        │
        ▼
 [Р.2б] Мгновенное вскипание
  ├─ m_flash = m_total × η_flash
  ├─ m_pool_evap = (m_total − m_flash) × η_pool
  ├─ m_evap = m_flash + m_pool_evap
  ├─ m_dot = m_flash / duration_s  (для Jet Fire)
  └─ Mg_total = m_total            (для BLEVE)
        │
   ┌────┴────────────────┐
   ▼                     ▼
[Р.3] Jet Fire       [Р.4б] Огненный шар BLEVE
 (m_dot, Ef=130)      (m = m_total)
        │
        ▼
 [Р.7] Число людей в зонах поражения
```

## Р.1 Суммарная масса жидкого топлива в резервуарном парке

**Реализация:** `app/core/calcs/tank_park/tank_mass.py`  
**Нормативная основа:** Ростехнадзор №412, п.7.1; расчёт массы горючего вещества.

$$m_{\text{total}} = V_{\text{tank}} \cdot N_{\text{tank}} \cdot \rho_{\text{liq}}, \quad \text{кг}$$

| Параметр | Обозначение | Ед. изм. | Источник |
|---|---|---|---|
| Объём одного резервуара | $V_{\text{tank}}$ | м³ | вход `tank.volume_m3` |
| Количество резервуаров | $N_{\text{tank}}$ | шт. | вход `tank.count` |
| Плотность жидкой фазы | $\rho_{\text{liq}}$ | кг/м³ | `fuels.py`: дизель 830; СУГ 520 |
| Суммарная масса жидкости | $m_{\text{total}}$ | кг | расчёт |

**Нормативная ссылка:** Принята как масса горючего вещества в системе по аналогии с Ростехнадзор №412, Приложение 1, п.7.1.

<a name="r2a"></a>
## Р.2а Испарение дизельного топлива из пролива

**Реализация:** `app/core/calcs/tank_park/evaporation_diesel.py`  
**Нормативная основа:** ГОСТ Р 12.3.047-2012, Приложение К; РД 03-409-01, п.3.4; Ростехнадзор №412, п.7.1.

### Р.2а.1 Скорость испарения

$$W = 10^{-6} \cdot \eta \cdot P_{\text{нас}} \cdot \sqrt{M}, \quad \text{кг/(м}^2\text{·с)}$$

| Параметр | Обозначение | Ед. изм. | Значение |
|---|---|---|---|
| Давление насыщенных паров при 20 °C | $P_{\text{нас}}$ | Па | ДТ-Л: ≈ **5 Па** (`diesel_Pnas_pa`) |
| Молярная масса топлива | $M$ | г/моль | Для C₁₂–C₁₄ ≈ **184** г/моль (`diesel_M_g_mol`) |
| Коэффициент ветровой нагрузки | $\eta$ | — | 1,0 (при скорости ветра ≤ 0,5 м/с) |

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Приложение К, формула (К.1).

> **Примечание:** Для дизельного топлива давление насыщенных паров при 20 °C очень мало (≈ 2–10 Па для ДТ-Л по ГОСТ 305-82), поэтому скорость испарения крайне мала — концентрация ТВС накапливается медленно. Значение 5 Па — консервативная оценка. Для конкретного сорта топлива уточнять по паспорту.

---

### Р.2а.2 Масса испарившегося топлива

$$m_{\text{evap}} = \min\!\left(W \cdot F_{\text{пр}} \cdot \tau,\ m_{\text{total}}\right), \quad \text{кг}$$

| Параметр | Обозначение | Ед. изм. | Источник |
|---|---|---|---|
| Площадь пролива | $F_{\text{пр}}$ | м² | вход `spill.area_m2` |
| Продолжительность испарения | $\tau$ | с | вход `spill.duration_s` |

Масса ограничена $m_{\text{total}}$ — всей массой жидкости в резервуарном парке.

**Нормативная ссылка:** РД 03-409-01, п.3.2; Ростехнадзор №412, Приложение 1.

---

### Р.2а.3 Масса газа в облаке ТВС

$$m_{\text{cloud}} = m_{\text{evap}} \cdot Z$$

| Параметр | Обозначение | Значение | Источник |
|---|---|---|---|
| Коэффициент участия в ТВС | $Z$ | **0,1** (`Z_tank` в `EngineConfig`) | РД 03-409-01, Табл. 1 — для жидких горючих на открытой площадке |

> **Сравнение с трубопроводным газом:** Для природного газа (POUO2) $Z = 0{,}5$. Для жидких горючих на открытой площадке стандарт задаёт $Z = 0{,}1$ ввиду того, что испаряется лишь поверхностный слой и облако не очень концентрированное.

---

### Р.2а.4 Удельная теплота сгорания с поправкой

$$E_{ud} = \beta \cdot E_{ud0}, \quad \text{Дж/кг}$$

| Параметр | Обозначение | Значение |
|---|---|---|
| Удельная теплота сгорания | $E_{ud0}$ | 43 · 10⁶ Дж/кг (`fuels.py`, дизель) |
| Коэффициент эффективности горения | $\beta$ | 1,0 |

---

### Р.2а.5 Энергозапас облака

$$E = m_{\text{cloud}} \cdot E_{ud}, \quad \text{Дж}$$

Энергозапас $E$ используется в расчёте ударной волны (§Р.6).

**Нормативная ссылка:** Ростехнадзор №412, п.7.1.5; РД 03-409-01, п.3.4.

<a name="r2b"></a>
## Р.2б Мгновенное вскипание СУГ (Flash Evaporation)

**Реализация:** `app/core/calcs/tank_park/flash_lpg.py`  
**Нормативная основа:** ГОСТ Р 12.3.047-2012, п.7.2; TNO Yellow Book (CPR 14E), гл. 2.

### Физическая основа

СУГ хранится в жидком состоянии под давлением насыщенных паров при температуре окружающей среды:

- Пропан: $T_{\text{кип}} \approx -42$ °C, $P_{\text{нас}}(+20°C) \approx 0{,}84$ МПа
- Бутан: $T_{\text{кип}} \approx -0{,}5$ °C, $P_{\text{нас}}(+20°C) \approx 0{,}23$ МПа

При разрушении резервуара давление мгновенно сбрасывается до атмосферного. Жидкость перегрета относительно новой точки кипения и **вскипает** (flash evaporation). Остаток образует пролив очень холодной жидкости.

---

### Р.2б.1 Доля мгновенного вскипания

**Термодинамическая оценка:**

$$\eta_{\text{flash}} = \frac{C_p \cdot \Delta T}{L_{\text{vap}}}$$

| Параметр | Значение для пропана |
|---|---|
| Удельная теплоёмкость жидк. фазы $C_p$ | 2 300 Дж/(кг·К) |
| Перегрев $\Delta T = T_{\text{окр}} - T_{\text{кип}}$ | 20 − (−42) = **62 К** |
| Теплота парообразования $L_{\text{vap}}$ | 370 000 Дж/кг |
| Расчётная $\eta_{\text{flash}}$ | $2300 \cdot 62 / 370000 \approx 0{,}385$ |

**Принятое значение по умолчанию:** $\eta_{\text{flash}} = 0{,}30$ (`lpg_flash_fraction`)

> **Обоснование:** Опытные данные показывают, что реальная доля вскипания ниже термодинамического предела из-за потерь тепла на дробление капель и перемешивание. Значение 0,30 принято как консервативная оценка (TNO Yellow Book, гл. 2, Табл. 2.3).

---

### Р.2б.2 Масса мгновенно испарившегося СУГ

$$m_{\text{flash}} = m_{\text{total}} \cdot \eta_{\text{flash}}, \quad \text{кг}$$

---

### Р.2б.3 Масса остаточной жидкости и испарение из пролива

$$m_{\text{жидк}} = m_{\text{total}} - m_{\text{flash}}, \quad \text{кг}$$

$$m_{\text{pool\_evap}} = m_{\text{жидк}} \cdot \eta_{\text{pool}}, \quad \text{кг}$$

| Параметр | Обозначение | Значение |
|---|---|---|
| Доля испарения из пролива | $\eta_{\text{pool}}$ | 0,10 (`lpg_pool_evap_fraction`) |

> Холодная жидкость СУГ испаряется медленно от тепла подстилающей поверхности. Принятые 10% — консервативная оценка за первые минуты инцидента.

---

### Р.2б.4 Суммарная масса газообразного СУГ

$$m_{\text{evap}} = m_{\text{flash}} + m_{\text{pool\_evap}}, \quad \text{кг}$$

---

### Р.2б.5 Эквивалентный расход для модели факела

$$\dot{m}_{\text{jet}} = \frac{m_{\text{flash}}}{t_{\text{duration}}}, \quad \text{кг/с}$$

Средний расход мгновенно испарившейся части — используется как $\dot{m}$ в расчёте факела (§Р.3).

---

### Р.2б.6 Масса для BLEVE-огненного шара

$$m_{\text{BLEVE}} = m_{\text{total}}, \quad \text{кг}$$

В консервативном сценарии **вся масса жидкого СУГ** в резервуарном парке участвует в огненном шаре.

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, п.7.2; Ростехнадзор №412, п.7.2.1.

## Р.3 Факельное горение (Jet Fire) — только СУГ

**Реализация:** `app/core/calcs/fire/jet_fire.py` (вызов через `_run_jet_fire_tank()`)  
**Нормативная основа:** ГОСТ Р 12.3.047-2012, Приложение Б, п.Б.1–Б.5.

Расчёт аналогичен §7.2.1 документа `METHODOLOGY_7_1_7_3.md`. Специфика для СУГ:

### Р.3.1 Длина факела

$$L_F = K \cdot \dot{m}_{\text{jet}}^{0{,}4}, \quad \text{м}$$

| Параметр | Значение | Нормативная ссылка |
|---|---|---|
| Коэффициент $K$ для СУГ (пропан, вертикаль) | **15** | ГОСТ Р 12.3.047-2012, Табл. Б.2 |
| Коэффициент $K$ для природного газа (для сравнения) | 12,5 | ГОСТ Р 12.3.047-2012, Б.17 |

### Р.3.2 Интенсивность теплового излучения

$$q(r) = E_f \cdot F_q(r) \cdot \tau(r), \quad \text{кВт/м}^2$$

| Параметр | Обозначение | Значение |
|---|---|---|
| Среднеповерхностная интенсивность | $E_f$ | **130 кВт/м²** (пропан) |

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Табл. Б.1.

Угловой коэффициент $F_q$ и пропускание атмосферы $\tau$ — по полным формулам ГОСТ Б.5–Б.15 (цилиндрическая модель). Описание см. §7.2.1.2–7.2.1.3 документа `METHODOLOGY_7_1_7_3.md`.

### Р.3.3 Зоны поражения

| Зона | Порог $q$, кВт/м² | Эффект |
|---|---|---|
| Безопасная | < 1,4 | — |
| Болевой порог | 1,4 | Ощущение боли |
| Ожоги 1-й степени | 4,2 | Поверхностные ожоги |
| Ожоги 2-й степени | 7,0 | Глубокие ожоги |
| Смертельное поражение | 10,5 | 50% летальность за 60 с |

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Табл. 1.

<a name="r4b"></a>
## Р.4б Огненный шар BLEVE (lpg)

**Реализация:** `app/core/calcs/fire/fireball.py` (вызов через `_run_fireball_bleve()`)  
**Нормативная основа:** ГОСТ Р 12.3.047-2012, п.7.2; TNO Green Book (CPR 14E), гл. 6.

**Масса вещества в огненном шаре** = суммарная масса СУГ в резервуарном парке:

$$m_{\text{fb}} = m_{\text{total}}, \quad \text{кг}$$

---

### Р.4б.1 Геометрия огненного шара

$$D_S = 5{,}33 \cdot m_{\text{fb}}^{0{,}327}, \quad \text{м} \tag{ГОСТ 7.2.1}$$

$$H = \frac{D_S}{2}, \quad \text{м} \quad \text{(высота центра шара)}$$

$$t_S = 0{,}92 \cdot m_{\text{fb}}^{0{,}303}, \quad \text{с} \tag{ГОСТ 7.2.2}$$

| Параметр | Описание |
|---|---|
| $D_S$ | эффективный диаметр огненного шара, м |
| $H$ | высота центра шара над землёй (приближение $H = D_S/2$) |
| $t_S$ | время существования огненного шара, с |

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, формулы (7.2.1)–(7.2.2).

---

### Р.4б.2 Коэффициент пропускания атмосферы

$$\tau(r) = \exp\!\left(-7 \cdot 10^{-4} \cdot \text{dist}\right)$$

$$\text{dist} = \max\!\left(0,\ \sqrt{r^2 + H^2} - \frac{D_S}{2}\right), \quad \text{м}$$

$\text{dist}$ — расстояние от ближайшей точки **поверхности** шара до объекта.

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, формула Б.4.

---

### Р.4б.3 Угловой коэффициент (сферическое приближение)

$$F_q(r) = \frac{a}{4 \cdot \left(a^2 + b^2\right)^{3/2}}$$

$$a = \frac{H}{D_S} + 0{,}5 = 1{,}0 \quad \text{(при } H = D_S/2\text{)}$$

$$b = \frac{r}{D_S}$$

> **Отличие от факела:** В `jet_fire.py` применяется полная цилиндрическая формула ГОСТ Б.5–Б.15. Для огненного шара применяется сферическое приближение (модель «твёрдого пламени»). Погрешность ~10–20% в ближней зоне по сравнению с формулой TNO гл.6.

---

### Р.4б.4 Интенсивность теплового излучения

$$q(r) = E_f \cdot F_q(r) \cdot \tau(r), \quad \text{кВт/м}^2$$

| Топливо | $E_f$, кВт/м² | Источник |
|---|---|---|
| СУГ (пропан) | **150** | TNO Green Book, гл. 6 (огненный шар) |
| Дизель | **47** | ГОСТ Р 12.3.047-2012, Табл. Б.1 |

---

### Р.4б.5 Пробит поражения тепловым излучением

$$P_r = -12{,}8 + 2{,}56 \cdot \ln\!\left(t_S \cdot q^{4/3}\right)$$

Вероятность поражения из пробита:

$$p = \frac{1}{2}\left[1 + \text{erf}\!\left(\frac{P_r - 5}{\sqrt{2}}\right)\right] \times 100\%$$

**Нормативная ссылка:** TNO Green Book (CPR 14E), гл. 7, Табл. 7.1; РД 03-418-01, Приложение 1.

<a name="r5"></a>
## Р.5 Пожар пролива (Pool Fire) — только дизель

**Реализация:** `app/core/calcs/tank_park/pool_fire.py`  
**Нормативная основа:** ГОСТ Р 12.3.047-2012, Приложение Б, формула Б.12–Б.13.

### Р.5.1 Геометрия пролива и пламени

**Диаметр пролива (эффективный):**

$$D_{\text{пр}} = \sqrt{\frac{4 \cdot F_{\text{пр}}}{\pi}}, \quad \text{м}$$

**Высота пламени — формула Томаса:**

$$L_F = 42 \cdot D_{\text{пр}} \cdot \left(\frac{\dot{m}^{\prime\prime}}{\rho_{\text{возд}} \cdot \sqrt{g \cdot D_{\text{пр}}}}\right)^{0{,}61}, \quad \text{м}$$

| Параметр | Обозначение | Значение |
|---|---|---|
| Площадь пролива | $F_{\text{пр}}$ | вход `spill.area_m2`, м² |
| Удельная скорость выгорания | $\dot{m}^{\prime\prime}$ | **0,040 кг/(м²·с)** для дизеля (`diesel_burn_rate_kg_m2_s`) |
| Плотность воздуха | $\rho_{\text{возд}}$ | 1,2 кг/м³ |
| Ускорение свободного падения | $g$ | 9,81 м/с² |

**Высота центра тяжести пламени:**

$$H_c = \frac{L_F}{2}, \quad \text{м}$$

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Приложение Б, формула Б.12 (формула Томаса).

---

### Р.5.2 Угловой коэффициент облучённости

Для пожара пролива применяется та же цилиндрическая модель ГОСТ Б.5–Б.15, что и для факела (`_fq_gost`):

- Длина цилиндра = высота пламени $L_F$
- Диаметр цилиндра = диаметр пролива $D_{\text{пр}}$
- Горизонтальное расстояние = $r$

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Приложение Б, формулы Б.5–Б.15.

---

### Р.5.3 Интенсивность теплового излучения

$$q(r) = E_f^{\text{pool}} \cdot F_q(r) \cdot \tau(r), \quad \text{кВт/м}^2$$

| Параметр | Значение | Источник |
|---|---|---|
| $E_f^{\text{pool}}$ для дизеля | **25 кВт/м²** (`diesel_Ef_pool_kw_m2`) | ГОСТ Р 12.3.047-2012, Табл. Б.1 |

---

### Р.5.4 Зоны поражения

Те же пороговые значения $q$ (1,4 / 4,2 / 7,0 / 10,5 кВт/м²), что и для факела (§Р.3.3).

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Табл. 1; РД 03-409-01, Приложение 4.

<a name="r6"></a>
## Р.6 Ударная волна при взрыве ТВС — только дизель

**Реализация:** `app/core/calcs/tvs/shockwave.py`, `app/core/calcs/tvs/probit_zones.py`  
**Нормативная основа:** РД 03-409-01, п.4; Ростехнадзор №412, Приложение 1.

Расчёт выполняется по **тем же формулам**, что и для природного газа (§7.3 документа `METHODOLOGY_7_1_7_3.md`), но с энергозапасом $E$ из §Р.2а.5 и параметрами дизельного топлива.

---

### Р.6.1 Масштаб длины

$$L_0 = \left(\frac{E}{P_0}\right)^{1/3}, \quad \text{м}$$

---

### Р.6.2 Приведённое расстояние

$$R_x = \frac{r}{L_0}$$

---

### Р.6.3 Дефлаграционный режим (класс пространства 5)

Для резервуарного парка принимается **дефлаграционный режим**, диапазон 5 (РД 03-409-01, Табл. 2):

$$V_g = 43 \cdot m_{\text{cloud}}^{1/6}, \quad \text{м/с}$$

| Параметр | Значение для дизеля |
|---|---|
| Коэффициент расширения $\sigma$ | **6,5** (`sigma_diesel` в `EngineConfig`) |
| Скорость звука $C_0$ | **330 м/с** (`EngineConfig.c0_m_s`) |

---

### Р.6.4 Давление и импульс ударной волны

$$P_x = \left(\frac{V_g}{C_0}\right)^2 \cdot \frac{\sigma-1}{\sigma} \cdot \left(\frac{0{,}83}{R_{x,P}^*} - \frac{0{,}14}{(R_{x,P}^*)^2}\right)$$

$$I_x = \frac{V_g}{C_0} \cdot \frac{\sigma-1}{\sigma} \cdot \kappa \cdot \left(\frac{0{,}06}{R_{x,I}^*} + \frac{0{,}01}{(R_{x,I}^*)^2} - \frac{0{,}0025}{(R_{x,I}^*)^3}\right)$$

$$\kappa = 1 - 0{,}4 \cdot \frac{(\sigma-1) \cdot V_g}{\sigma \cdot C_0}$$

**Перевод в физические единицы:**

$$\Delta P = P_x \cdot P_0, \quad \text{Па}$$

$$I^+ = I_x \cdot \frac{P_0^{2/3} \cdot E^{1/3}}{C_0}, \quad \text{Па·с}$$

**Нормативная ссылка:** РД 03-409-01, формулы (4.4)–(4.5).

---

### Р.6.5 Зоны поражения ударной волной

**Разрушение остекления:**

| Зона | $\Delta P$, кПа | Характер |
|---|---|---|
| Зона 3 (слабое) | 1–2 | Трещины, отдельные стёкла |
| Зона 2 (среднее) | 2–5 | Массовое разрушение |
| Зона 1 (полное) | 5–10 | Полное разрушение рам |

**Разрушение зданий:**

| Категория | $\Delta P$, кПа | Характер |
|---|---|---|
| A (полное) | > 100 | Обрушение несущих конструкций |
| B (сильное) | 70–100 | Обрушение стен |
| C (среднее) | 30–70 | Разрушение стен, сохранение каркаса |
| D (слабое) | 12–30 | Деформация перегородок |
| E (лёгкое) | 5–12 | Деформация ненесущих конструкций |

**Нормативная ссылка:** ГОСТ Р 12.3.047-2012, Табл. 2; РД 03-409-01, Приложение 5.

---

### Р.6.6 Пробит поражения людей ударной волной

$$P_r = 5 - 0{,}26 \cdot \ln\!\left[\left(\frac{17500}{\Delta P}\right)^{8{,}4} + \left(\frac{290}{I^+}\right)^{9{,}3}\right]$$

где $\Delta P$ — Па, $I^+$ — Па·с.

**Нормативная ссылка:** TNO Green Book (CPR 14E), гл. 8, формула (8.1); РД 03-418-01, Приложение 1.

<a name="r7"></a>
## Р.7 Оценка числа людей в зонах поражения

**Реализация:** `app/core/calcs/tank_park/people_exposure.py`  
**Нормативная основа:** Ростехнадзор №412, п.8; РД 03-409-01, Приложение 6; МЧС Методика 2009, п.3.

**Площадь каждой зоны поражения** (предположение об открытом кругообразном пространстве):

$$A_{\text{зоны}} = \pi \cdot r_{\text{зоны}}^2, \quad \text{м}^2$$

**Расчётное число людей в зоне:**

$$N_{\text{зоны}} = A_{\text{зоны}} [\text{га}] \cdot \rho_{\text{перс}}, \quad \text{чел.}$$

| Параметр | Обозначение | Источник |
|---|---|---|
| Радиус зоны поражения | $r_{\text{зоны}}$ | из расчётов §Р.3, Р.4, Р.5 |
| Плотность персонала | $\rho_{\text{перс}}$ | вход `exposure.people_density_per_ha`, чел/га |

Расчёт выполняется для зон всех реализованных сценариев теплового поражения:
- Зоны факела (только СУГ)
- Зоны пожара пролива (только дизель)
- Зоны огненного шара (оба топлива)

**Нормативная ссылка:** Ростехнадзор №412, п.8.3; МЧС Методика 2009, п.3.2.

## Известные расхождения и TODO

### ⚠️ Расхождения (не критические для диплома)

1. **Огненный шар: сферическое vs точная формула TNO**  
   В `fireball.py` применяется упрощённая сферическая формула для $F_q$ вместо полной из TNO Green Book гл.6. Погрешность ~10–20% в ближней зоне. Для диплома приемлемо.

2. **Значение $P_{\text{нас}} = 5$ Па для дизеля**  
   Нижняя консервативная оценка. Для ДТ зимнего или летнего сорта конкретной марки значение может отличаться. Рекомендуется уточнять по паспорту на топливо.

3. **$\sigma = 6{,}5$ для дизеля**  
   Принято из ГОСТ Р 12.3.047, Табл. Д.1 для «тяжёлых» углеводородов. Для C₁₂–C₁₄ теоретическое значение $\sigma \approx 6{,}5$–$7{,}0$ — расхождение несущественно.

4. **Число людей в зонах ТВС-взрыва (дизель)**  
   `run_people_exposure()` учитывает только **тепловые** зоны (jet_fire, pool_fire, fireball). Зоны ударной волны по числу людей — отдельная задача; в текущей реализации оцениваются только площади зон через `probit_zones.py`.
